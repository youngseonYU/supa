설치 및 최초 실행

이 HTML 파일 하나와 Supabase 프로젝트만 있으면 됩니다.

1. 프로젝트 구조

maker-portfolio.html 하나에 화면, 스타일, 기능, 설치 안내가 모두 포함되어 있습니다. 외부 패키지는 CDN에서 불러옵니다.

2. Supabase 준비

  1. Supabase에서 새 프로젝트를 만듭니다.
  2. 아래 Supabase SQL 탭의 코드를 SQL Editor에서 한 번 실행합니다.
  3. Authentication → Users에서 교사 이메일 계정을 만듭니다. 이메일 확인이 필요하면 확인 처리합니다.
  4. Project Settings → API에서 Project URL과 anon public key를 복사합니다.

3. 최초 실행

  1. 이 HTML 파일을 브라우저에서 엽니다. 학교 웹서버나 정적 호스팅에 올리면 QR 접속이 편리합니다.
  2. 상단 설정에서 Supabase URL, Anon Key를 입력하고 저장합니다.
  3. AI 다듬기를 사용할 경우에만 Gemini API Key를 입력합니다.
  4. 교사 탭에서 로그인하고 프로젝트를 만든 뒤 QR을 학생에게 배포합니다.

4. 환경 설정

별도 .env 파일은 사용하지 않습니다. Supabase URL, Anon Key, Gemini API Key, 선택 모델은 브라우저 LocalStorage에 저장됩니다. 공용 PC에서는 사용 후 설정값을 지우거나 브라우저 사이트 데이터를 삭제하세요.

5. 운영 전 확인

  • 학생 사진은 portfolio-photos 버킷에 저장됩니다.
  • 기본 SQL은 로그인 없는 학생 기록 조회/수정을 지원하기 위해 교실 파일럿용 공개 정책을 포함합니다. 실제 학교 운영에서는 학생 인증 또는 보안 RPC 도입을 권장합니다.
  • Gemini는 학생이 “AI 글 다듬기”를 눌렀을 때만 호출됩니다. 일반 저장은 AI를 호출하지 않습니다.
  • QR 링크가 다른 기기에서도 열리려면 파일을 HTTPS 정적 호스팅에 배포하세요.
